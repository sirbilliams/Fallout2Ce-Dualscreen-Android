Fallout 2 Community Edition for Android, built for the AYN Thor and other dual-screen handhelds: the game on the top screen, a touch companion on the bottom. Bring your own copy of Fallout 2; no game files are included.

**Install:** download `Fallout2-Dualscreen.apk` below. It installs over 2.0.1 and keeps your saves and settings.

## New: Mod Organizer
- **MODS button on the main menu.** Each mod lives in its own folder in a shared mod store. You can turn mods on/off and drag to set order. A mod lower in the list wins when two change the same file. Game files are never overwritten.
- **Add mods from a .zip file.**
- **Profiles.** Each profile has its own mod list, its own saves, and its own ddraw.ini / mod ini files. The Vanilla profile is your current game exactly as before, untouched.
- **Restart after changes.** Leaving the MODS screen after changes restarts the game to the main menu so the changes load.

## Fixes
- **Broken "Continue" save.** The automatic suspend save could fire while no game was running, for example at the title screen or during a map load. Continue then loaded a map with only floor tiles: no walls, critters or items, and the character named "None". It now only saves while a game is actually running. Already-broken Continue saves cannot be repaired automatically: load your last manual save instead.

Regression test: `suspend_gate_test`.
